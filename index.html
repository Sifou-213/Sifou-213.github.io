Optimisation du chargement des camions (Bin Packing 3D)Truck loading optimisation (3D Bin Packing)

Question métierBusiness question
Comment charger chaque camion pour baisser le coût de transport par pièce et éviter les dommages causés par les chargements non conformes ?
How should each truck be loaded to lower the transport cost per item and avoid damage caused by non-compliant loads?
DémarcheApproach
Modélisation en problème de Bin Packing 3D, résolu par un algorithme génétique hybride qui construit le chargement couche par couche. Contraintes réelles intégrées : catalogue des 11 véhicules de la flotte, orientations autorisées pour chaque colis, limite de temps de calcul.
Modelled as a 3D Bin Packing problem and solved with a hybrid genetic algorithm that builds the load layer by layer. Real constraints included: catalogue of the 11 fleet vehicles, allowed orientations for each box, computation time limit.
LivrableDeliverable
Application web Python (Flask) avec API REST, qui calcule le plan de chargement et l’affiche en 3D couche par couche.
Python web app (Flask) with a REST API that computes the load plan and shows it in 3D, layer by layer.
